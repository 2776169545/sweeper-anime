# 🌸 幻渊扫雷物语

一座 **2048×2048（419 万格）** 的二次元扫雷 + 挂机冒险世界。

## 玩法简介

- **扫雷探索**：越靠近中心雷越少，越往外越密（边缘常出现 5~8 大数字）。踩雷不会结束游戏，只扣金币。
- **挂机收益**：收入 = 已翻开格子的数字总和/秒，离线也持续积累。
- **世界奇观**：湖泊（湖中仙女祝福）、火山（周期性喷发）、魔王城堡（5 层雷墙+地下城副本）、世界之壁、5 座可探索副本（各掉限定稀有道具）。
- **成长体系**：道具（探针/爆破/矿工/护盾/沙漏/传送/自动探针/藏宝图/勇者之剑/世界级道具）、收藏品（被 8 颗雷包围的逆天功效）、星尘转生强化、成就与里程碑。
- **冒险氛围**：像素猫咪、四季世界事件（迷雾/夜幕/日食/血月，各有专属特效与音乐）、可缩放小地图、自由编辑的道具栏。

## 操作

左键翻开 · 右键插旗 · 滚轮/按钮缩放 · 拖动平移 · 快捷键 1-8 使用道具栏 · 点击小地图跳转放大

## 部署（GitHub Pages）

1. 在 GitHub 新建一个**空仓库**（不要勾选 README）。
2. 本地执行（把 `你的仓库地址` 换成实际地址，如 `https://github.com/你的名字/幻渊扫雷.git`）：
   ```
   git remote add origin 你的仓库地址
   git push -u origin main
   ```
   （若仓库名/地址已配好，也可以直接运行 `push-to-github.cmd` 或看下方手动命令。）
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。
4. 等待 1~2 分钟，访问 `https://你的名字.github.io/仓库名/` 即可游玩（刷新即自动读档）。
