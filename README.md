## 🎮 玩法速览

- **扫雷探索**：左键翻开方格，数字 = 周围 8 格内的雷数。越靠近中心雷越稀少，越向外越密集——边缘地带常出现 **5~8 的大数字**。
- **踩雷不终结**：触碰地雷只扣除金币并暂停收入；金币归零会触发陨石雨，摧毁部分已探索区域。
- **挂机收益**：收入 = 已翻开格子的**数字总和 / 秒**（数字越大收益越高），关闭游戏也在离线积累。
- **探索限制**：每次操作目标须距已探索区域 20 格以内——防止投机取巧；世界级道具可无视此规则。

## 📝 技术说明

- 纯前端单文件（HTML + CSS + JS），**无任何外部依赖与网络请求**，离线可用。
- 地图 2048×2048（419 万格）由可复现的种子生成；存档经位压缩后写入 localStorage（约 1.4MB）。
